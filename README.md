# Kristin Silva static site

This folder is ready for GitHub Pages.

## Files
- `index.html` — homepage / biography
- `essay.html` — The Value of a Trend
- `style.css` — desktop + mobile responsive styling
- `assets/hero.jpg` — supplied essay hero image

## Publish on GitHub Pages
1. Create a new public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment choose “Deploy from a branch”.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub to provide the live Pages URL.

## Before launch
- Replace the two `href="#"` placeholders in the footer with your exact LinkedIn and Instagram URLs.
- The site loads Switzer through Fontshare. If you later want to self-host a licensed copy, replace the Fontshare `<link>` in both HTML files with local `@font-face` declarations.
- Studio Quiche and Working With Designers links are already included.
